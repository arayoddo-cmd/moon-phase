# 🌙 달 모양 관측소 (지구와 달의 운동 3차시: 달의 위상 변화)

달의 **공전**과 **위상 변화**를 모형으로 관찰하고, 지구에서 보이는 달의 모양이 바뀌는 까닭을 찾는 수업 자료예요.
교과서 Ⅲ. 태양계 › 3. 달의 운동 (교과서 252~255쪽, 학습지 13~15쪽) 내용을 따라가요.

> 시리즈: ① 자전과 일주 운동 (`diurnal-motion`) → ② 공전과 연주 운동 (`annual-motion`) → ③ 달의 위상 변화 (이 자료)
> 1·2차시와 같은 화면 구성·조작법이고, 결과는 같은 구글 시트의 **'달의 위상 현황'** 탭에 모여요.

## 화면

| 보기 | 보여 주는 것 |
|---|---|
| 🌙 공전 모형 | 가운데 지구, 공전하는 달, 오른쪽에서 오는 햇빛 (교과서 그림과 같은 배치). 🔭 비스듬히 / ⬇️ 위에서(북극 위) / **👀 지구에서 보기**(탐구에서 스마트 기기로 찍은 모습, 왼쪽 아래에 위에서 본 위치 지도) |
| 보기 버튼 | **☀👁 빛 받는 쪽·보이는 쪽**(노랗게 칠한 밝은 반쪽과 분홍 반원, 겹친 부분 = 보이는 모양. 실제 달 표면 보기에서는 노란 반원도 그려요), **🌓 8개 위치 한눈에**(우주에서 본 달 + 바깥에 지구에서 본 모양), **㉮~㉵ 위치**(교과서 탐구 번호), **👀 지구에서 본 모양 창**(오른쪽 위) |
| 🌗 그림처럼 · 🎯 달 확대 | 기본으로 달을 교과서 그림처럼 태양 쪽 반은 노랗게, 반대쪽은 어둡게 칠하고 둥근 테두리를 그려요(끄면 실제 달 표면). **🎯 달 확대해서 따라가기**를 누르면 화면 중심이 달로 옮겨지고 크게 보이며, 공전해도 따라가요. 두 손가락(마우스 오른쪽)으로 끌면 중심을 직접 옮길 수 있어요. 확대해서 지구가 화면 밖으로 나가면 달 옆에 **☀ 햇빛 화살표**, 화면 가장자리에 **🌍 지구는 이쪽** 표시(점선), 왼쪽 아래에 **위에서 본 위치 지도**가 나와서 위치 관계를 잃지 않아요. |
| 🕐 하루 동안 | 남쪽 하늘에서 초승·상현·보름·하현·그믐달이 하루 동안 동 → 서로 뜨고 지는 모습(시계, 해 위치, 1시간마다 지나온 자리). 빠르기(🐢 느리게 1시간=2초 / 보통 1시간=1초 / 빠르게), **+1시간**. **📅 다음 날 같은 시각**을 누르면 시계는 그대로 두고 하루가 지나서, 흐린 "어제 이 시각" 달보다 오늘 달이 동쪽으로 약 13° 옮겨 간 것(주황 화살표)과 모양이 바뀐 것이 보여요. |
| 🌇 저녁 하늘 | 해가 진 직후 남쪽을 보고 선 하늘(왼쪽 동, 오른쪽 서). 음력 2일 서쪽 초승달 → 7~8일 남쪽 상현달 → 15일 동쪽 보름달, 지나온 달이 흐리게 남아요. 오른쪽(또는 왼쪽) 위 **⬇️ 위에서 본 모습** 지도에서 해 진 직후 관측자(지평선 오른쪽 서, 왼쪽 동)와 달의 공전 위치를 함께 보여 줘서, 태양 – 지구 – 달의 각이 곧 서쪽 지평선에서 달까지의 각이라는 걸 연결해요. **하늘의 달을 누르면** 그 달이 하루 동안 뜨고 지는 모습으로 바뀌어요. 뜬 직후에 멈춰 있다가 ▶를 누를 때마다 남중할 때 · **해가 진 직후(오후 6시, 저녁 하늘에서 본 자리)** · 지기 직전에서 차례로 멈춰요. 해가 진 직후가 뜰 때(보름달)나 남중(상현달)과 겹치면 한 번만 멈춰요. (🌇 저녁 하늘로 돌아가기) 하늘의 달(2·3·4·6·7~8·10·12·15일경)은 태양 – 지구 – 달 각을 15°의 배수(15°·30°·45°·60°·90°·120°·135°·180°)로 맞춰 놓아서, 뜨고 남중하고 지는 시각이 모두 정각으로 나와요(예: 4일경 오전 9시에 떠서 오후 9시에 짐). |

## 👩‍🏫 수업 모드 (TV용)

넓은 화면(TV·노트북, 폭 1000px 이상)에서는 조작 버튼이 **관측 화면 오른쪽 세로 칸**에 모여 있어서 스크롤하지 않고 조작할 수 있어요. 관측 화면은 화면 높이에 맞춰 크게 나와요. (좁은 화면에서는 버튼이 관측 화면 아래에 있어요)

위에서·비스듬히 볼 때 달은 원근 때문에 옆면이 보여도 늘 **정확히 태양 쪽 반원**이 노랗게 보이도록 그려요.
① 정리 카드 5번(27일 vs 29.5일)에는 지구가 공전하는 동안 27일 뒤에는 아직 보름달이 아니고 며칠 더 돌아야 다시 보름달이 되는 그림이 있어요(빈칸 답 "2"는 그림에 쓰지 않았어요).
① 정리 카드 9번은 수업 PPT의 **달의 크기**(지름 약 1/4, 질량 약 1/80, 표면 중력 약 1/6)예요. 지구 아래에 달 4개를 늘어놓아 지름을 비교하는 그림이 있어요.

탭 5개: ① 달의 공전 ② 위상이 변하는 까닭 ③ 위상 변화 순서(지금 달 위치를 분홍 고리로 강조) ④ 저녁 하늘의 달 ⑤ 하루 동안 뜨고 지는 달.
학습지와 같은 빈칸 정리 카드가 아래에 큰 글씨로 나와요. 수업 모드에서는 화면을 TV 너비에 맞게 넓히고(최대 1880px), 시뮬레이션 속 글자(이름표·안내 문구·시계·날짜)를 화면 너비에 따라 1.4~1.8배로 키워요. 탐사 모드(학생 태블릿)는 원래 크기 그대로예요. 수업 모드에서만 **달 위치 버튼**(삭·초승달·상현달·보름달·하현달·그믐달)이 있어요. 정리 카드 글씨는 TV에서 멀리서도 읽히게 크게(화면 너비에 따라 28~46px) 나오고, 가려진 빈칸에는 **초성 힌트**(예: 자전축 → ㅈㅈㅊ, 숫자는 ?)가 보여요. 빈칸을 누르면 답이 나와요. 수업 모드에서는 마우스 위치에 **빨간 레이저 포인터 고리**가 따라다니고, 누르면 물결이 퍼져서 학생들이 선생님이 가리키는 곳을 쉽게 찾아요. 가운데 점이 실제로 누르는 자리예요. 왼쪽 아래 **🔴 포인터 켜짐/⚪ 꺼짐** 버튼으로 끄고 켤 수 있어요(브라우저가 기억해요).

## 🧑‍🚀 탐사 모드 (학생 태블릿용)

1. **임무 1. 달의 공전**: 위에서·지구에서 각각 반 바퀴 이상 공전시켜 본 뒤 보고서 7문제
2. **임무 2. 모형으로 위상 관찰**: 교과서 탐구처럼 ㉮~㉵ 8곳에 달을 놓고, **⬇️ 위에서 본 모형만 보고** 지구에서 보일 모양을 8가지 중 골라요. 맞혀야 👀 지구에서 보기(🔒)가 열려서 찍은 모습으로 확인해요. 위치를 바꾸면 다시 위에서 보기로 돌아가고, 두 번 틀리면 ☀👁 빛 받는 쪽·보이는 쪽을 켜 보라는 힌트가 나와요. **💡 달 모양 찾기 요령**이 이 임무에 있어요. → 삭·망·상현·하현, 위상 변화 까닭 6문제 (오개념 "지구 그림자 때문" 보기 포함)
3. **임무 3. 위상 순서와 저녁 하늘**: "음력 15일 해 진 직후 달은 어디에, 어떤 모양?" **예측 → 재생으로 확인**, **🕐 하루 동안** 보기와 방향 비교 후 9문제 (하루 동안 움직이는 방향, 상현달 방향, 13° 동쪽 이동, 보름달일 때 태양 위치, 가장 오래 보이는 달, 순서, 추석, 하현달 날짜, 1년 보름달 횟수)
- 문항과 정리 카드는 학습지 2-1·2-3(13~15쪽), 교과서 252~255쪽, 수업 PPT에 있는 내용만 써요. (달이 뜨는 시각, 50분씩 늦게 뜨는 것 등은 넣지 않았어요)
4. **임무 4. 확인 퀴즈**: 형성평가 유형 22문제 (상현·보름·하현 순서와 관측 간격, 궤도 A~H 그림, 교과서 스스로 확인하기 A·B 그림, 햇빛이 왼쪽에서 오는 그림, 그믐·상현·보름 관측 시간, 해 진 뒤 저녁 하늘 세 장 그림 — 학습지 15·20쪽, PPT, 교과서 255쪽에서 가져왔어요)

- **통과 기준 임무 1~3은 70%, 임무 4는 60%**: 임무마다 처음 고른 답이 정답인 비율(임무 2는 모양 기록 8개 + 문제)이 기준 이상이어야 통과하고, 앞 임무를 모두 통과해야 다음 임무가 열려요. 기준에 못 미치면 **🔁 다시 도전하기**로 그 임무의 문제를 처음부터 다시 풀어요(관찰 체크와 임무 3 예측은 남고, 임무 2는 모양 기록도 다시 해요). 시트에는 '완료 / 재도전 필요'와 '(재도전 N번)'이 함께 기록돼요.
- 임무 2·4에는 펼쳐 볼 수 있는 **💡 달 모양 찾기 요령**(빛 받는 쪽 + 보이는 쪽, 삭초상망하그, 날짜 표)이 있어요.
- "하루에 약 13°", "음력 7~8일" 같은 수치는 학습지 빈칸 내용이라 문항에 넣었어요.
- 교사 화면에서 반별 완료 인원, "한 번에 맞힌 수", 틀린 답(예: "㉰: 오른쪽 반원")을 볼 수 있어요.

## 🎮 마지막 도전 · 달 카드와 지구 포대 (임무 4를 통과하면 열려요)

1. **1단계 · 달 카드 뒤집기**: 카드 12장(6쌍)을 두 장씩 뒤집어 **달 사진 ↔ 이름**(삭·초승달·상현달·보름달(망)·하현달·그믐달) 짝을 찾아요. 짝을 찾으면 음력 날짜가 함께 떠요. 적게 뒤집을수록 점수가 커요(6번이면 600점). 배치는 할 때마다 바뀌어요.
2. **2~4단계 · 지구 포대: 이 모양의 달을 쏴라!** (연속): 지구에서 본 달 사진(6가지: 삭·초승달·상현달·보름달·하현달·그믐달. 상현망간·하현망간의 달은 내지 않아요)이 나오면, 북극 위에서 본 공전 궤도 8자리 중 그 달을 쏴요. 맞히면 곧바로 다음 목표가 나와요.
   - 2단계(30초): 햇빛이 언제나 **오른쪽**에서 (소행성 최대 6개)
   - 3단계(30초): 햇빛이 언제나 **왼쪽**에서 (소행성 최대 6개)
   - 4단계(45초): 햇빛이 목표마다 **오른쪽·왼쪽 섞여서** (소행성 최대 7개)
3. **5단계 · 지구 포대: 이 날짜의 달을 쏴라!** (45초 연속): "음력 22~23일의 달"처럼 날짜가 나오고, 달 8개가 공전 방향으로 **돌아요**(1초에 12°). 햇빛도 섞여서 나와요(소행성 최대 9개). 지금 그 날짜 자리(30° 안)에 와 있는 달을 쏴요.

- 포대는 지구 위에 있어요: **지구에서 달을 바라보는 방향 = 쏘는 방향**. 쏘고 싶은 달 쪽을 누르면 포대가 돌고, 손을 떼면 발사해요.
- 판의 달은 **우주에서 본 모습**(햇빛 쪽 반이 밝음)이라 겉모습이 아니라 **자리**로 판단해요. 4·5단계에서는 햇빛이 목표마다 **오른쪽 또는 왼쪽**에서 와요(교과서 문제처럼). 햇빛 방향이 바뀌면 판 가운데에 "☀ 햇빛 방향이 바뀌었어요! 이제 왼쪽에서 와요 ←"가 뜨고, 햇빛 쪽 가장자리의 큰 빛 덩어리와 화살표가 깜빡이며 알림음이 나요. 0.7초 동안은 쏠 수 없어서 확인할 틈이 있어요.
- 🪨 소행성이 0.3~0.85초마다 나타나요(단계가 올라갈수록 많고 빨라져요). 궤도 안쪽을 **가로지르는 것**과 지구 둘레를 **빙빙 돌며 한쪽을 계속 막는 것** 두 가지가 있어요. **소행성에 막히면 포탄 한 발을 잃어요.** 틈을 노려 쏴야 해요.
- 목표마다 포탄 3발(1발 100 · 2발 60 · 3발 30점 + 연속 명중 보너스). 빗나가면 "그 달은 지구에서 ○○달(음력 약 ○일)로 보여요"가 나오고, 3발을 다 쓰면 정답 자리를 초록 원으로 잠깐 보여 준 뒤 다음 목표로 넘어가요.
- 게임 속 달 사진은 조금 더 밝게, 초승달·그믐달은 조금 더 두껍게 그려요.
- 게임 기록은 임무 성적과 따로 시트의 **'달의 위상 게임 현황'** 탭(최고 점수·도전 횟수·마지막 점수·모두 성공·최고 성공률)에 모여요. 교사 화면에 **반 대항 지구 포대 성공률**(나온 목표 중 명중 비율, 학생별 최고의 반 평균)과 반별 최고 점수가 나와요.
- 🎵 배경음악·효과음은 게임 화면에서만 나와요. 오른쪽 아래 🎵 버튼으로 끌 수 있어요.

## 결과 받기

1차시 Apps Script를 그대로 쓰면 **따로 할 일이 없어요.** 같은 주소로 보내면 시트에 '달의 위상 현황' 탭이 저절로 생겨요.

이 폴더(`index.html`, `README.md`)를 GitHub 새 저장소(예: `moon-phase`)에 올리고 Settings → Pages에서 main 브랜치를 켜요.

## 참고

- 달과 지구 크기, 거리는 보기 쉽게 키워서 그렸어요. 달 궤도 기울기(5°)는 넣지 않았어요.
- 음력 날짜는 위상 변화 주기 29.5일로 어림한 값이에요.
- 저녁 하늘 그림의 달은 교과서 그림처럼 밝은 쪽을 세워서(오른쪽) 그렸어요.
- 지구에서 본 달의 위상(지구에서 본 모양 창, 8개 위치 바깥 그림, 👀 지구에서 보기, 저녁 하늘, 하루 동안, 임무 2 보기, 퀴즈 그림)은 **실제 달 사진**으로 그려요. 사진: NASA 달 정찰 궤도선(LRO) 앞면 모자이크, 퍼블릭 도메인 (NASA/GSFC/Arizona State University). index.html 안에 들어 있어서 따로 올릴 파일은 없어요. 우주에서 본 달(공전 모형, 퀴즈 궤도 그림)은 교과서처럼 태양 쪽 반을 노랗게 칠해요.
